# Solar Forecast

A small web app that estimates daily solar energy using Open-Meteo tilted-surface
irradiance.

## Use

Open the published site, tap the map to choose a location, enter panel settings,
and select **Get 16-day forecast**. Favorites are stored in the browser on that
device.

## Data and map

- Forecast data: Open-Meteo
- Map tiles: OpenStreetMap contributors
- Map library: Leaflet

Forecast values are estimates, not guarantees of electrical production.
